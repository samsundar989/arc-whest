## Task and exact decision rule

For each random He-initialized, bias-free ReLU MLP (width 1024, depth 16), predict all neurons' expected post-ReLU activations under standard Gaussian input. Only final-layer mean squared error (MSE) enters the score. For network i, let `F_i` be counted flopscope FLOPs and `B = 2^41`; its Phase-2 adjusted score is `MSE_i × max(0.1, F_i/B)`. The competition score is the **arithmetic mean of these per-network products**. Phase-2 lambda is zero: residual CPU time is not added to `F_i`, but exceeding 0.4 seconds residual on any MLP is a failure. Wall and memory caps also matter. A failed MLP's prediction is replaced with zeros, so failure identities must be checked, not just average error. Local counted FLOPs reproduce the official-package subprocess operation ledger; the grading server adds an unexplained `2^24` FLOPs, a +0.0122% offset. No local absolute wall time proves server safety.
