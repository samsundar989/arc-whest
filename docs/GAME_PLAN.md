## Target architecture

- Full propagated mean and covariance.
- Complete factored third-cumulant source history, with explicit birth/feed conventions.
- Regenerated per-neuron fourth-order core and a consistently connected nonlinear moment program.
- Exact contraction fusion and verified P4/Strassen savings.
- Shared source coordinates chosen to protect consumed D3/D21 information, including cross-factor interactions, where experiments support compression.
- One deterministic, shape-generic single-file export using only grader-legal imports; no diagnostic reference dependency.

We retain this architecture family. Its precise closure/core/storage combination is not yet validated as state of the art. The next work identifies that combination rather than adding isolated terms to an unmatched chain.
