## First candidate: fuse shared-right products in D21

In the standing L2 `_dslice21`, let C=A_L diag(w2b), with `*` denoting elementwise multiplication. The current numerator is

```
2 (A_D*M) @ M.T + (M*M) @ A_D.T
  + 6 (A_L*M) @ C.T + 3 (A_L*C) @ M.T.
```

The proposed numerator is

```
[2 (A_D*M) + 3 (A_L*C)] @ M.T
  + (M*M) @ A_D.T + 6 (A_L*M) @ C.T.
```

Apply the existing division by three and off-diagonal mask unchanged. This is distributivity: four matrix products become three. Preserve D3, all Wick-table terms, raw-to-centered conversions, exact birth subtraction, all ages, the **existing scalar K4**, saturation, precision, final-layer shortcut and shape fallbacks. No new physical K4 source or rank approximation is needed.

This differs from the failed symmetric-packing intervention, which sought discounts within an existing multiplication. Here a multiplication disappears by combining two terms that share M.T. Preserve the old packing negative. The independent architecture review identifies the historical inventory and source locations.

At depth 16, 14 actual wide multiplication calls disappear, representing 105 lineage-equivalent products in a historical 797-equivalent dominant-work model. Approximately 13% is a **planning estimate**, not a measured reduction in total official cost, runtime or score. Fusion moves scaling/addition before a float32/Strassen multiplication, so exact real arithmetic does not imply bit identity. The new left operand also needs a measured lifetime. There is no new metered result in this review.

Build new files from frozen own-code parents. Start with one fixed parent/backend for diagnosis; check the best-public L4 configuration as well before calling anything a better submission. ## Second route: make compact storage reproduce the working recurrence

The compact template computes diagonal variance and third-central-moment births from Gaussian-only formulas, whereas the standing estimator uses its full Wick table and centered cumulants with incoming corrections. Its D21 coefficient also differs from the integrated kernel; normalization must be aligned before changing a number. The existing off control is therefore not evidence that faithful all-age compression is bad.

A useful exact bridge for each standing lineage is:

```
Source.A = A_L; Source.P = M; Source.w2 = w2b;
Source.s = Source.e = 0;
Source.Z = A_D; Source.L = I;
new matrix-core feed fields absent.
```

This reproduces the represented K3 tensor at full residual rank with matching orientations, mask and normalization. The general split `A_D = P diag(s) + 3 A diag(e) + Z L.T` is exact only while its residual is retained exactly. Declaring that residual rank16 is an approximation, not an identity.

Retain the standing `_layer` semantics and compare input slices, every centered moment, next births and final readout at full shared/full residual rank. A tensor self-oracle for the simplified compact recurrence cannot replace this differential. Use deterministic synthetic fixtures first; no protected truth is needed. Once full-rank parity is established, separately test one compression choice, preserving all ages and pricing every join/reconstruction. Do not stack term pruning, scalar-K4 deletion, new matrix-core K4 and rank reduction into one control.

This audit can run independently after the first contraction slice is synthesized, or alongside its queued checks with isolated file ownership. It must not postpone a ready first candidate. It remains the credible route to larger savings after a modest exact improvement.

## Why the current signed-source project is not the critical path

The n8 covariance failure is too large to be roundoff: its inspected L2 minimum eigenvalue is about -0.231, and the fixed next-state variance decomposes as +0.03325 without the K4 component and -0.15097 from that component. This local decomposition is not a recursively K4-disabled run. The n4 trajectory also amplifies a sizeable K4 signal while variance collapses; a numerical floor is not a physical or stability proof.

The synthetic bank is transported linearly while the backbone evolves nonlinearly. Exact contraction of that bank does not make it a consistent source for the evolving moment state. Conversely, a useful approximate cumulant method need not encode an exact probability law at every step. The ARC paper's latest v2 provides polynomial/fixed-depth theory and empirical ReLU evidence, not a theorem that our particular finite-width closure is exact or stable. [ARC v2](https://arxiv.org/html/2605.05179v2).

There is no justified universal fixed-rank exact solution to the packet's nonlinear signed-law demand. The review gives two scalar distributions with the same first four moments but different post-ReLU means. That obstructs an exact four-moment sufficient state; it does not prove approximate K4 is useless. Mark causal signed-law implementation **deferred as a next-candidate strategy**, preserving all accepted toy identities and failed gates. Do not close the scientific K4 lane.

After a competitive baseline, one bounded *approximate* K4 extension may retain a declared harmonic core/residual, consistent consumers/births and a predeclared validity domain. Stability mechanisms such as damping or PSD repair change the approximation and must be costed and tested, not silently called exact. An off-shape fallback is legitimate if explicit, but tiny tests must force the actual target branch when validating its math. The public V29 code disables its regenerated K4 outside 1024 x 16; its tiny smoke is not evidence for that branch. [Primary-source audit](research/2026-09-12_frontier_update.md).
